# 已确定的重要决策

## D-001：系统仅供内部销售使用

应用的唯一操作者是销售或内部管理人员。客人只观看销售设备，或接收离线导出文件。

## D-002：禁止远程客人入口

不提供客人模式、公开深链、二维码在线菜单或应用内分享。已有同类遗留能力不得重新启用。

## D-003：交付方式仅为离线文件

客人交付物为自包含 PNG/PDF。文件通过微信、拷贝等应用外渠道传递，系统本身不负责发送。

## D-004：保持纯前端 PWA

应用继续使用原生 Web 技术和 Service Worker，优先保证平板本地运行及离线能力，不引入常驻业务后端。

## D-005：菜品库是单一真源

菜品图片和主数据只在菜品库保存一份，套餐通过 ID 引用；菜单内差异使用覆盖字段表达。

## D-006：WebDAV 仅用于内部同步

WebDAV 及其 Cloudflare Worker 代理不面向客人。凭据保存在受控环境中，不进入仓库或公开导出物。

## D-007：平板横屏优先

UI 和交互以销售手持平板的现场演示为第一优先级，手机端仅维持基本可用。

## D-008：正式文档保持最小集合

项目只维护产品、架构、UI 和决策四类正式文档。阶段评审、临时建议和原型说明中的有效结论应合并到这里，随后删除原文件。

## D-009：点菜页采用左右分栏

平板横屏下，宴席与套餐选择固定在左侧，菜品展示位于右侧；窄屏通过响应式规则收敛尺寸。原独立预览页已并入正式入口，不再维护第二套页面。
