# UI 设计规范

## 1. 文档定位

本规范是“山水 S 酒店宴席菜单系统”的设计与前端实现基线，适用于展示模式、管理模式、定制单、设置、同步与离线 PNG/PDF 导出。设计稿、组件、CSS 和验收均以本文参数为准；同类组件不得在业务页面内另设尺寸、颜色或交互规则。

系统是酒店销售人员使用的内部平板工具，一级设备为约 1280 × 800 的横屏平板。客人只观看销售设备或接收离线 PNG/PDF，不提供客人账号、自助操作、公开链接或在线二维码菜单。

### 1.1 设计目标

1. **宴席展示优先**：菜名、菜品图片、套餐价格和当前宴席是最高信息层级。
2. **新中式且克制**：以朱红、暖金、宣纸米白和墨褐构成品牌感，不使用大面积高饱和金色、复杂纹样或强玻璃拟态。
3. **平板触控优先**：所有核心操作可触摸完成，不依赖悬停、右键或隐蔽手势。
4. **离线一致**：字体回退、图标和动效不得依赖运行时网络资源；屏幕展示与导出物保持相同的信息顺序、图片裁剪和品牌层级。
5. **高密度但不拥挤**：管理端允许更高信息密度，展示端保留更多留白；两者共用令牌与组件状态。

发生冲突时按以下顺序处理：可用性与无障碍 > 数据与操作安全 > 本规范的组件一致性 > 单页面视觉偏好。新增例外必须记录在 `docs/DECISIONS.md`，不得只留在设计稿或局部 CSS 中。

### 2.3 字体层级

根字号保持 `16px`，不得禁用系统字体缩放。

- 标题与品牌：`"Noto Serif SC", "Songti SC", "STSong", Georgia, serif`，用于品牌名、宴席名、套餐名、菜名和 H1–H3。
- 界面与数据：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`，用于正文、按钮、表单、价格和状态。
- 价格、统计和排序号使用 `font-variant-numeric: tabular-nums`。
- 正文不得使用书法字体；远程字体不得成为唯一字体；功能文字不得小于 `12px`。

### 2.4 间距、圆角、边框、阴影

间距采用 4px 基础网格：`0、4、8、12、16、20、24、32、40、48、64px`。组件内部不得使用其他间距；仅封面响应式定位可使用 `vw/vh/clamp()`。

- 圆角：`radius.sm=8px`、`md=12px`、`lg=16px`、`xl=24px`、`full=999px`。
- 边框：默认 `1px solid color.border.default`；选中和错误 `2px`，使用内描边或预留空间避免尺寸跳动。
- 卡片阴影：`0 4px 12px rgba(58,46,38,0.08)`。
- 卡片悬浮：`0 8px 20px rgba(58,46,38,0.12)`。
- 弹出层：`0 12px 32px rgba(28,22,16,0.18)`。
- 模态：`0 20px 56px rgba(28,22,16,0.24)`。
- 焦点环：`0 0 0 3px rgba(37,99,235,0.32)`，与控件外缘间隔 `2px`。

暗色主题阴影透明度依次提高到 `0.24、0.32、0.40、0.48`，并保留 1px 边框，不能只靠阴影区分层级。

## 3. 布局、栅格与响应式

### 3.1 基准

- 正式点菜页采用左右结构：左侧选择宴席与套餐，右侧展示当前套餐菜品。
- 左侧套餐面板可折叠；套餐切换与右侧菜品渐隐、渐显使用同一动画时间轴。
- 右侧保留前后浏览入口和菜品卡片详情入口，不能因布局折叠而失去操作能力。
- 设计基准 `1280 × 800px` 横屏；页面安全区左右 `24px`、上下 `16px`，与 `env(safe-area-inset-*)` 取较大值。
- 主内容最大宽 `1440px` 并居中；封面图片可全宽。
- 横屏 12 列、列间距 `16px`、外边距 `24px`；竖屏 8 列、间距 `16px`、外边距 `20px`；手机 4 列、间距 `12px`、外边距 `16px`。
- 左分类栏展开 `160px`、折叠 `48px`；顶部应用栏 `56px`，套餐切换栏与管理工具栏 `64px`。

### 3.2 断点

| 范围 | 规则 |
| --- | --- |
| `≥1440px` | 内容最大 `1440px`；菜品卡 4 列，统计卡最多 4 列 |
| `1024–1439px` | 一级横屏平板；菜品卡 3 列，管理抽屉 `720px` |
| `768–1023px` | 竖屏平板；菜品卡 2 列，抽屉宽 `86vw`、上限 `720px` |
| `480–767px` | 应急窄屏；菜品卡 2 列，弹窗宽 `calc(100% - 32px)` |
| `<480px` | 应急手机；图文管理卡可横排，统计卡 1 列，底部操作固定 |

断点按内容宽度，不按设备型号。任何断点不得隐藏唯一操作入口或状态说明。

### 3.3 触控与滚动

- 最小触摸目标 `44 × 44px`，相邻目标视觉间距至少 `8px`。
- 拖拽手柄 `44 × 44px`，与卡片点击区分离；拖拽启动阈值 `6px`，长按 `300ms`。
- 横向滚动区域露出下一项 `24px` 或显示分页点。
- 固定栏不得遮挡末项；滚动容器底部补白至少为固定栏高度加 `16px`。
- 悬停仅为鼠标增强，触屏必须有可见入口。

## 4. 卡片规范

### 4.1 原则与基础参数

卡片用于组织一个可独立理解、选择或操作的信息对象。同一列表不得混用圆角、阴影、标题位置和图片比例。不可点击卡不显示抬升悬停。

- 宽度由栅格决定；最小 `180px`，普通内容最大 `420px`，设置卡可占满容器。
- 最小高：纯文字 `112px`，统计 `120px`；图文卡由 `4:3` 图片和内容决定。
- 内边距：标准 `16px`、紧凑 `12px`、展示大卡 `24px`。
- 圆角：默认 `16px`；弹窗内嵌套卡 `12px`。
- 背景 `color.bg.surface`；边框 `1px solid color.border.default`。
- 静态卡无阴影；可点击卡默认使用卡片阴影。
- 标题 `16px / 24px、600`，最多 2 行；正文 `14px / 22px、400`，最多 3 行；辅助文字 `12px / 18px`。
- 标题与正文间距 `4px`，正文与元数据 `8px`，内容组与操作区 `16px`。

### 4.2 图文排版

- 菜品主图固定 `4:3`、`object-fit: cover`，遵循已保存裁剪位置，禁止拉伸。
- 竖卡图片在上、文字在下；内容内边距 `12px 16px 16px`。
- 横卡图片在左，`120 × 90px`；卡最小高 `114px`，图文间距 `16px`。
- 顶部图片与外卡共享 `16px` 上圆角、下角为 `0`；横卡缩略图四角 `12px`。
- 图片序号左上距 `8px`，最小 `24 × 24px`，`12px / 18px、600`；复杂照片上使用 `rgba(251,247,238,0.88)` 底。
- 中文名优先；英文名紧随其下、间距 `2px`、最多 2 行。
- 标签位于底部，间距 `4px`，最多 2 个，更多显示“+N”。
- 操作放右上或底部操作区，不覆盖菜品主体；仅关闭和选择序号可覆盖图片。

### 4.3 状态

| 状态 | 参数 |
| --- | --- |
| 默认 | 默认边框；可点击卡使用卡片阴影 |
| 悬停 | `translateY(-2px)`、悬浮阴影、强边框，`150ms` |
| 按下 | 位移归零、`scale(0.98)`、阴影减为 `0 2px 6px rgba(58,46,38,0.10)`，`80ms` |
| 焦点 | 3px 蓝色焦点环，保留选中边框 |
| 选中 | 2px 品牌红内描边、品牌浅底、右上 `24px` 选中标记 |
| 多选次序 | 标记显示 1、2、3…，`12px、700` 白字 |
| 禁用 | 次级背景、整体不透明度 `0.56`、无阴影/位移、`not-allowed` |
| 加载 | 保持尺寸；骨架底 `#E7DED0`、高光 `#F5EFE5`，`1200ms linear` |
| 错误 | 2px 危险色边框，底部 `12px / 18px` 错误说明，不只显示红框 |

触屏不执行悬停位移。减少动态效果时取消位移、缩放和骨架扫光。

### 4.4 卡片预设

#### A. `TextCard` 纯文字卡

适用于设置入口、菜单说明、同步摘要和导出选项。最小高 `112px`，内边距 `16px`。结构为可选 `20px` 图标、标题、最多 3 行正文和尾部状态/箭头。整卡可点击时内部不再放第二个主操作；两个以上操作改用底部按钮区。

#### B. `DishCard` 菜品图文卡

适用于展示菜单、菜品库和选菜器。横屏 3 列、最小宽 `190px`、图片 `4:3`、文字区最小高 `72px`。结构为图片、序号、中文名、英文名和最多 2 个标签。展示态点击开详情；管理态点击选中，编辑使用独立 `44px` 图标按钮。同一网格不混入无图横卡。

#### C. `StatCard` 数据统计卡

适用于菜品数、套餐数、定制总价、同步状态。最小 `200 × 120px`，内边距 `20px`。结构为 `12px` 标签、`28px / 36px` 数值、`12px` 趋势或说明。一个卡只表达一个指标；趋势同时使用图标/文字，不能只用红绿。

#### D. `ActionCard` 操作卡

适用于导入、导出、备份恢复和 WebDAV。最小高 `88px`，内边距 `16px`，图标容器 `40 × 40px`。危险操作用危险色图标与文字，但默认背景仍为表面色；执行前通过确认弹窗说明影响。

#### E. `PackageHeroCard` 套餐展示卡

仅用于当前套餐页头。宽 `100%`，横屏最小高 `120px`，内边距 `24px`，圆角 `16px`。品牌红底，白色标题，暖金眉题和单位，价格 `32px / 40px、800`。左信息右价格；宽度 `<600px` 时上下排列、间距 `16px`。卡内最多 2 个操作。

#### F. `EmptyCard` 空状态卡

适用于无菜品、无搜索结果和无备份。占满网格列，最小高 `200px`，内边距 `32px`。结构为 `48px` 图标、`18px` 标题、`14px` 说明和可选 1 个主按钮；说明必须给出下一步。

## 5. 按钮规范

### 5.1 层级

每个页面、弹窗或抽屉的可见操作组最多 1 个主按钮。取消、返回用次按钮或文字按钮；删除、恢复默认等不可逆操作用危险按钮。文案采用“动词 + 对象”，如“保存套餐”“生成 PDF”。

| 类型 | 默认样式 | 使用 |
| --- | --- | --- |
| `Primary` | 品牌红底、白字 | 当前容器唯一主要推进操作 |
| `Secondary` | 表面底、强边框、主文字 | 取消、返回、次级编辑 |
| `Tonal` | 品牌浅底、品牌红字 | 中优先级操作 |
| `Text` | 透明底、品牌红字 | 低优先级、工具栏溢出 |
| `Danger` | 危险红底、白字 | 删除、覆盖、清空；实心仅用于确认阶段 |
| `IconButton` | 透明或表面底 | 关闭、更多、前后切换、拖拽，必须有 `aria-label` |

圆形图标按钮仅用于关闭、播放、前后切换等惯例；其余图标按钮用 `12px` 圆角。难以仅靠图标理解的业务动作必须带文字。

### 5.2 尺寸

| 尺寸 | 高 | 水平内边距 | 字体 | 图标 | 圆角 |
| --- | ---: | ---: | --- | ---: | ---: |
| `lg` | `48px` | `20px` | `16px / 24px、600` | `20px` | `12px` |
| `md` | `40px` | `16px` | `14px / 20px、600` | `18px` | `12px` |
| `sm` | `32px` | `12px` | `13px / 18px、600` | `16px` | `8px` |

文字按钮最小宽 `64px`，主/次按钮最小宽 `88px`；图文间距 `8px`，按钮组间距 `8px`。图标按钮视觉尺寸可为 `40px`，但点击区至少 `44px`。

### 5.3 状态

| 状态 | 主按钮 | 次 / 图标按钮 |
| --- | --- | --- |
| 默认 | `#B23A2E` | 表面底 + 默认/强边框 |
| 悬停 | `#9F3127`，`0 4px 10px rgba(178,58,46,0.20)` | 次级底 + 强边框 |
| 按下 | `#8F2A20`、`scale(0.98)` | 品牌浅底、`scale(0.98)` |
| 焦点 | 当前状态 + 3px 蓝色焦点环 | 同左 |
| 加载 | 保持原宽；文字透明；中央 `18px` 转圈；禁止重复点击 | 同左 |
| 禁用 | `#E4DDD3` 底、`#A99D91` 字、无阴影 | 透明/禁用底、禁用字、默认边框 |

颜色过渡 `120ms ease-out`，按压 `80ms`，松开 `120ms`。加载转圈 `800ms linear infinite`；操作超过 `800ms` 显示加载，超过 `10s` 显示“仍在处理中”，超过 `30s` 提供取消或重试。禁用必须设置 `disabled` 或 `aria-disabled` 并阻止事件；加载使用 `aria-busy="true"`。

## 6. 动效规范

动效用于说明空间关系、确认输入和减少跳变，不用于装饰性吸睛。一次操作最多一个主运动方向。

| 令牌 | 时长 | 缓动 | 用途 |
| --- | ---: | --- | --- |
| `motion.instant` | `80ms` | `ease-out` | 按压、开关 |
| `motion.fast` | `120ms` | `ease-out` | 颜色、边框、图标 |
| `motion.base` | `180ms` | `cubic-bezier(0.2,0,0,1)` | 卡片、菜单、Toast |
| `motion.slow` | `240ms` | `cubic-bezier(0.2,0,0,1)` | 弹窗、抽屉、列表重排 |
| `motion.stage` | `450ms` | `cubic-bezier(0.32,0.72,0.34,1)` | 封面进入菜单 |

只动画 `transform` 和 `opacity`；颜色、阴影可短过渡。不得动画宽高和定位引发大面积重排，内容展开确需高度变化时上限 `240ms`。

- 卡片：悬停上移 `2px/150ms`；按下 `scale(0.98)/80ms`。
- 按钮：颜色 `120ms`；按压 `scale(0.98)`，图标按钮可到 `0.94`。
- 下拉：从 `translateY(-4px)` 和透明进入，`180ms`；退出 `120ms`。
- 居中弹窗：遮罩 `180ms`；内容从 `scale(0.96)` 与透明进入，`240ms`；退出 `180ms`。
- 右抽屉：从 `translateX(100%)` 进入，`240ms`；遮罩同步 `180ms`。
- Toast：底部上移 `12px` 淡入 `180ms`；普通停留 `4000ms`，撤销 `6000ms`；退出 `120ms`。
- 列表新增：上移 `8px` 淡入 `180ms`；删除先淡出 `120ms`，其余项重排 `240ms`。
- 拖拽：被拖项阴影升高并 `scale(1.02)`；其余项位移 `180ms`。
- Tab：选中标记移动 `180ms`；内容只交叉淡化 `120ms`。
- 封面舞台：垂直切换 `450ms`，不叠加视差、旋转或背景缩放。

输入后 `100ms` 内必须反馈；动画可反向中断。保存、同步、导出以真实结果触发。手势提示最多循环 3 次，每次 `1600ms`，之后静止。`prefers-reduced-motion: reduce` 下时长降为 `1ms`，取消位移、缩放、自动轮播和循环动画。

## 7. 表单与选择控件

- 输入框高 `44px`，多行最小高 `96px`，水平内边距 `12px`，文字 `14px / 22px`，圆角 `10px`。
- 标签在上，`14px / 22px、600`，距控件 `6px`；辅助/错误文案 `12px / 18px`，距控件 `6px`。
- 默认为表面底和 1px 边框；聚焦为焦点色边框 + 3px 焦点环；错误为 2px 危险边框、图标与文字。
- 字段组垂直间距 `16px`，并排字段 `12px`。
- 占位符只做格式示例，不能代替标签。必填用“必填”或 `*` 并在表单开头解释。
- 复选/单选视觉 `20 × 20px`，完整点击区至少 `44px` 高。
- 开关 `44 × 24px`，滑块 `20px`，旁边始终有文字标签。
- 分段控件高 `40px`、内边距 `4px`，单项最小宽 `72px`，最多 4 项。
- 标签页高 `48px`，文字 `14px / 20px、600`，选中下划线 `2px`。
- 筛选 Chip 高 `36px`，圆角 `999px`，水平内边距 `12px`；选中同时改变背景、文字和图标。

## 8. 弹窗、抽屉与反馈

### 8.1 弹窗

- 常规宽 `560px`、复杂表单 `720px`、确认 `400px`；最大宽 `calc(100vw - 40px)`，最大高 `calc(100vh - 40px)`。
- 内容区独立滚动，标题与操作区固定；圆角 `16px`，使用模态阴影。
- 标题区最小高 `64px`、左右内边距 `24px`；标题 `22px / 30px`。
- 内容内边距 `24px`；底部操作区 `16px 24px 24px`，按钮间距 `8px`。
- 关闭按钮 `44 × 44px`，右上距 `10px`，支持 Esc。存在未保存数据时遮罩点击不关闭。
- 打开后焦点进入首个操作，关闭返回触发器，焦点限制在弹窗内。

危险确认写明对象和后果，如“删除套餐「锦绣良缘」？菜单引用将移除，菜品库原数据保留。”主按钮写“删除套餐”，不用含糊的“确定”。

### 8.2 抽屉

横屏右侧宽 `720px`；竖屏 `86vw`、上限 `720px`；`<600px` 占满。顶栏高 `64px`，内容内边距 `24px`，底部操作区最小高 `72px`。抽屉必须有文字化“完成/关闭”，不能只靠遮罩或手势。

### 8.3 Toast、横幅与状态

- Toast 宽 `320–480px`，最小高 `48px`，内边距 `12px 16px`，圆角 `12px`。
- 成功停留 `4000ms`、信息 `5000ms`、撤销 `6000ms`；错误不自动关闭或至少 `8000ms` 并提供关闭/重试。
- Toast 最多 2 行；长说明用横幅或弹窗。
- 页内横幅最小高 `48px`，内边距 `12px 16px`，左侧 `20px` 状态图标，圆角 `12px`。
- 反馈包含动作和结果，如“已导出 12 页 PDF”。离线是持续状态，用状态条或横幅，不连续弹 Toast。

### 8.4 加载、空态与恢复

- 首次加载 `<300ms` 不显示；`300–800ms` 显示局部骨架；`>800ms` 显示文字状态。
- 骨架与最终内容同尺寸，图片骨架保持 `4:3`。
- 空态说明“为什么为空 + 下一步”，最多 1 个主操作。
- 错误保留已输入内容，提供重试、返回或本地备份路径。
- WebDAV 失败区分离线、认证失败、路径错误和服务不可用，不统一显示“同步失败”。

## 9. 图标与图片

### 9.1 图标

- 统一线性 SVG，视框 `24 × 24px`、描边 `1.75px`、圆角端点和连接。
- 常规 `20px`、按钮内 `18px`、辅助 `16px`、空态 `48px`。
- 图标继承文字色，不在 SVG 写死颜色。
- 禁止 emoji 作为正式功能图标；禁止混用实心、线性和彩色拟物风格。
- 图标按钮必须有可访问名称，装饰图标设 `aria-hidden="true"`。
- 删除、警告、成功等必须配文字，颜色和图标都不能是唯一载体。

### 9.2 菜品图片

- 源图建议至少 `1200 × 900px`，显示裁剪固定 `4:3`。
- 列表推荐 `640 × 480px`，详情建议 `1280 × 960px`。
- 不做全局美颜、锐化或改变菜品与器皿；只允许用户控制的裁剪、旋转和有限亮度校正。
- 缺图使用占位图标和“暂无图片”，背景为图片底色。
- 加载失败显示重试且不塌缩卡片。
- 上传、裁剪、展示和导出读取同一裁剪数据。

## 10. 导航规则

- 展示态只突出宴席、套餐、分类、菜品、价格和详情；管理入口置于品牌菜单或明确工具栏。
- 顶栏左侧为品牌与业务上下文，中部为导航/筛选，右侧为搜索与操作。
- 当前宴席、套餐和分类持续可见或一次操作可查看。
- 面包屑只用于超过两级的管理路径；展示态不使用。
- 右键菜单必须有触屏等价的“更多”按钮；手势有可见入口或首次提示。
- 导航选中态同时使用背景/指示线和字重变化，不能只改文字颜色。

## 11. 无障碍

### 11.1 对比度

- 正文及按钮文字至少 `4.5:1`。
- `18px` 常规或 `14px` 粗体以上的大文字至少 `3:1`。
- 控件边界、图标、焦点指示与相邻颜色至少 `3:1`。
- 禁用控件须有语义属性并不可触发。
- 文字叠图时用不透明度至少 `0.72` 的表面遮罩，或确保最差区域仍达 `4.5:1`。

### 11.2 键盘与读屏

- 所有功能可用键盘完成，Tab 顺序与视觉顺序一致。
- 不移除焦点样式；卡片使用真实 `button/a` 或完整实现 role、tabindex、Enter 和 Space。
- 弹窗使用 `role="dialog"`、`aria-modal="true"`、`aria-labelledby`。
- 保存、同步、导出结果用 `aria-live="polite"`，阻断错误用 `assertive`。
- 表单错误通过 `aria-describedby` 关联，提交后首个错误获焦点。
- 放大到 `200%` 不丢失功能或出现双向滚动，文本间距增大后不裁切。

### 11.3 文案

- 根语言 `zh-CN`，英文菜名局部 `lang="en"`。
- 时间统一 `YYYY-MM-DD HH:mm`；金额统一 `¥12,888` 或 `12,888 元/席`，选定后全局一致。
- 避免只写“是/否/确定”；错误文案按“发生了什么。影响或原因。下一步。”组织，建议不超过 60 个汉字。

## 12. 组件命名与实现

- 设计组件：`类别/类型/尺寸/状态`，如 `Button/Primary/Lg/Loading`、`Card/Dish/Selected`。
- CSS：组件 `c-`、布局 `l-`、工具类 `u-`、状态 `is-` 或属性，如 `.is-selected`。
- JavaScript 钩子使用 `data-js`，不得依赖纯视觉类。
- 主题和尺寸通过 `[data-theme="dark"]`、`.c-button--lg` 等属性/修饰类表达，不复制组件。

```css
:root {
  --color-brand-primary: #B23A2E;
  --color-brand-hover: #9F3127;
  --color-brand-active: #8F2A20;
  --color-bg-canvas: #F5F0E6;
  --color-bg-surface: #FBF7EE;
  --color-text-primary: #3A2E26;
  --color-border-default: #DED6C9;
  --color-focus: #2563EB;
  --space-1: 4px;
  --space-2: 8px;
  --space-4: 16px;
  --space-6: 24px;
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
  --shadow-card: 0 4px 12px rgba(58,46,38,0.08);
  --motion-fast: 120ms;
  --motion-base: 180ms;
  --ease-standard: cubic-bezier(0.2,0,0,1);
}
```

旧令牌如 `--primary`、`--surface` 可在迁移期映射到新令牌，但新增组件只能使用新语义令牌。迁移完成前不得删除旧令牌，以兼容已有本地版本和导出样式。每个组件必须定义类型、尺寸、状态、可访问名称、交互性、加载和错误行为；业务页面不得覆盖组件内部圆角、字体、阴影和状态色。

## 13. 离线、性能与稳定性

- UI 必需字体、SVG、占位图和样式随 PWA 本地缓存，不依赖 CDN。
- 首屏关键 CSS 不超过 `80KB gzip`；单个通用 SVG 不超过 `4KB`。
- 超过 100 张图片时懒加载；首屏可见图优先，其他图明确宽高避免布局偏移。
- 交互反馈目标 `100ms` 内，滚动与动画目标 `60fps`；中端平板不持续使用大面积模糊或多层滤镜。
- `backdrop-filter` 只用于封面信息浮层和模态遮罩，并提供不透明背景回退。
- 离线仍可浏览、编辑和导出；联网功能说明离线状态并保留本地数据，不阻塞页面。

## 14. 离线 PNG/PDF

- 固定浅色品牌主题和白色/宣纸米白背景，不跟随暗色模式。
- 按目标尺寸单独排版，不直接截图当前响应式视口。
- A4 竖版 `210 × 297mm`，四周安全边距 `16mm`；内容不得越界。
- 图片保持 `4:3` 和裁剪焦点，至少 `150dpi`，正式打印建议 `300dpi`。
- 中文菜名不得跨页；单个菜品的图片、中英文名不得拆页。
- 页眉页脚距纸边至少 `10mm`，页码 `10pt / 14pt`。
- 导出前校验宴席名、套餐名、价格、顺序、中英文名、裁剪、分页和缺图。
- 不包含在线链接、远程二维码、WebDAV 地址、内部账号、编辑按钮或同步状态。
- 字体不可用时用系统回退并重新测量分页，不能输出文字重叠。

## 15. 验收清单

### 15.1 设计交付

- 使用本文令牌，无孤立颜色、字号、圆角和阴影。
- 新组件包含适用的默认、悬停、按下、焦点、选中、加载、禁用和错误状态。
- 提供 `1280 × 800` 横屏、`768 × 1024` 竖屏和 `390 × 844` 应急手机稿。
- 标注溢出、空数据、最长中文名、英文名两行、无图和离线状态。
- 提供键盘焦点顺序、弹窗返回焦点和危险操作文案。

### 15.2 开发验收

- 在 `1280 × 800`、`1024 × 768`、`768 × 1024`、`390 × 844` 无不可达操作、遮挡或非预期横向滚动。
- 触摸目标不小于 `44 × 44px`，按钮和卡片状态符合本文。
- 键盘可完成核心流程，焦点清晰，弹窗焦点不逃逸。
- 浅/暗主题对比度达标，`prefers-reduced-motion` 生效。
- 离线可浏览、编辑并导出 PNG/PDF。
- 导出名称、顺序、价格和裁剪与屏幕一致，且固定浅色。
- 功能修改后运行 `cd src && npm test`；涉及离线缓存、样式资产或导出依赖时同时运行 `npm run build`。

### 15.3 视觉回归

基准画面至少包含：展示封面、三列菜品列表、菜品详情、菜品库、定制单、设置页、编辑弹窗、危险确认、空态、加载、同步失败、暗色模式和 A4 首尾页。差异超过 `2px` 位移、一个字体层级或一个颜色令牌时必须评审。

## 16. 禁止事项

- 不新增客人端、公开分享链接、在线二维码菜单或客人账号界面。
- 不把 WebDAV 或内部同步入口暴露在展示主流程或导出物中。
- 不使用小于 `11px` 的文字、小于 `44px` 的独立触控目标或只靠颜色表达状态。
- 不给同类卡片、按钮、弹窗创建页面级私有样式。
- 不使用永久循环装饰动画、强弹跳、3D 翻转或大面积视差。
- 不拉伸、替换或自动改造菜品与器皿，不让响应式改变保存的裁剪。
- 不依赖悬停、右键、遮罩点击或手势作为唯一完成方式。
- 不在导出物显示编辑态、暗色主题、内部凭据、同步信息或联网元素。
