# 产品目标与功能

## 产品定位

山水 S 酒店宴席菜单系统是销售专用的内部工具。销售人员在平板上向客人现场展示菜单、维护菜品与套餐、制作定制报价，并导出离线文件交付客人。

客人不是系统用户。系统不提供客人账号、客人自助操作、公开链接、二维码在线菜单或应用内传输能力。

## 核心场景

1. 销售切换宴席类型和套餐，展示价格、菜品图片及中英文介绍。
2. 内部人员维护菜品库、套餐结构、排序、图片裁剪和名称覆盖。
3. 销售按客户需求换菜、加菜、改价并生成定制单。
4. 导出自包含的 PNG/PDF，通过应用外渠道离线交付。
5. 在内部设备间通过 WebDAV 拉取或发布菜单数据。

## 功能范围

- 多宴席、多套餐展示与搜索
- 菜品详情和图片浏览
- 菜品库及菜单 CRUD
- 拖拽排序、批量录入、图片裁剪
- 定制单、总厨单、整份菜单导出
- 本地存储、备份恢复、JSON 导入导出
- PWA 安装与离线缓存
- 内部 WebDAV 同步

## 明确不做

- 客人端或客人登录
- 在线菜单分享、远程深链或二维码交付
- 微信、短信、邮件等应用内发送
- 依赖联网才能打开的客人交付物
- 未经授权把菜单数据发布到外部服务

## 成功标准

- 平板横屏下展示清晰，销售能快速切换和修改菜单。
- 离线状态仍可浏览核心菜单并完成本地操作。
- 屏幕展示与导出结果一致，图片裁剪、名称、价格不漂移。
- 数据操作可恢复，发布和同步失败有明确提示。
