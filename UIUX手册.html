菜单系统 · UI/UX 设计规范手册

山水S酒店 · 婚宴菜单系统（平板 / 手机 PWA）· 版本 v7 · 修订 2026-08-11
设计方向：新中式 · 红金克制（Direction C）。 以宣纸米白为纸、品牌红为主色、克制金为点缀， 衬线标题（Noto Serif SC）提仪式感，分类按「凉菜 / 主菜 / 主食点心」分组，用金色细线分区。 目标气质：高端、克制、有节庆感，但不堆砌。所有界面（点菜 / 管理 / 定制单）共用同一套令牌，确保一致。

2 · 字体排印

字体族

衬线 --serif： Noto Serif SC — 用于标题、宴席名、菜名、品牌字。

无衬线 --sans： 系统默认（PingFang / 微软雅黑）— 用于正文、说明、输入框、按钮。

字号阶梯（px）

角色字号字重
宴席抬头 / 大标题34–44700
区块标题（壹·主菜）24–30700
菜名20–22（标准）／可放大至 35600
正文 / 说明13–15400
备注 / 次要14–15400
导出图（定制单）额外支持三档字号（标准 / 大 / 特大，缩放系数 1 / 1.3 / 1.6），专为中老年客户在手机上阅读优化——字号与行距同步放大，画布宽度不变，确保字号相对更大。

3 · 间距、圆角与栅格

间距令牌

统一用 4 的倍数：8 / 12 / 16 / 22 / 48。卡片内边距 16–20，区块间距 14–22，页面左右安全边距 22（移动端）/ 48（导出图）。

圆角令牌

--r-md 12px（卡片/输入框）· --r-lg 16px（弹窗/大卡）· --r-pill 999px（标签/胶囊按钮）。

响应式断点

设备栅格列数
iPad 横屏 1280×800（主目标）自适应，多列
手机 ≤ 820px强制 3 列（硬约束）
窄屏 ≤ 640px选择器网格 2 列

原则：手机端无论如何不能跌破 3 列网格；平板充分利用横向空间。

4 · 组件规范

主按钮 .mg-btn.primary

品牌红底白字，圆角 --r-md，hover 描边加深。用于主操作（新增、生成图片、保存）。

次按钮 / 幽灵

白底描边，用于次要操作（取消、设置）。危险操作用 --danger 红字。

输入框 .cs-input

白底、1px 描边、--r-md。抬头「客户·宴席类型」为并列双输入框。

标签 / 分类章

胶囊形，金线描边；分类标题用衬线 + 金色细线（壹·主菜 风格）。

弹窗 .modal

居中卡片，--r-lg，遮罩点击关闭；标题衬线，操作区右对齐 + 主按钮。

Toast / 提示条

暖金底说明条（--hint-bg）；危险/成功用对应语义色。轻量、不打断。

5 · 三大界面规范

① 点菜屏 orderScreen客户视角
顶栏：品牌 + 宴席选择 + 搜索
套餐条 pkgbar（切换套餐）
Hero 宴席横幅
菜品列表：按 凉菜/主菜/主食点心 分组
点击菜品 → 详情大图弹窗
只读展示，不编辑。网格手机端 3 列。
② 管理屏 manageScreen运营视角
单行车：标签(菜品库/菜单)+上下文+设置
菜品库：统一录入，图片只存一份
菜单：宴席→套餐条（可拖拽排序）
设置：折叠菜单（云端拉取/导入/导出…）
批量拖图 → 自动建「待命名」菜品
数据分两层：菜品库(主数据+图) 与 菜单(只存 id 引用)。
③ 定制单屏 customScreen销售视角
抬头：客户姓氏 · 宴席类型（可编辑）
菜品列表（克隆自选中套餐，纯内存）
每行：换菜 / 备注 / 移除
底部：＋添加菜品 + 本单总价(可编辑)
存为图片 → 导出弹窗
纯内存草案，不回写标准菜单；刷新即弃。
三屏切换： 通过品牌下拉（点菜 / 管理 / 定制单）切换 #orderScreen / #manageScreen / #customScreen 的 hidden。切换时顶栏的宴席选择/搜索在管理与定制单下隐藏。

6 · 定制单导出规范

定制单导出是面向客户的报价单，需兼顾「正规感」与「长辈可读」。导出弹窗遵循以下标准：

维度规范
版本带图版（每菜 4:3 缩略图，三列网格）／ 无图版（纯文字，菜名后跟备注，更紧凑正式）
格式PNG（高清位图，2×DPR）／ PDF（纯前端生成，JPEG 内嵌，可打印/转发）
界面大小三档：标准 1.0 / 大 1.3 / 特大 1.6——字号与行距同步缩放，照顾老年人
抬头「客户姓氏 · 宴席类型」可编辑；右上角「本单总价（元/桌）」可编辑
备注带图版：备注紧跟菜名下方（品牌红）；无图版：备注内联为「菜名（备注）」
文件名客户-宴席类型-定制单.png / .pdf
预览弹窗内实时预览，随版本/字号/格式切换刷新
1 · 选版本带图版 / 无图版（卡片单选，选中态红边暖底）
2 · 选大小标准 / 大 / 特大（胶囊按钮，放大字号行距）
3 · 选格式PNG / PDF（胶囊按钮）
4 · 预览实时缩略预览
5 · 生成下载到本地

7 · 无障碍与适老化

  • 阅读字号： 定制单导出提供三档界面大小（标准/大/特大），字号与行距同步放大，画布宽度不变 → 客户在手机上看到相对更大的字。
  • 高像素： 导出 PNG 采用 2×DPR 栅格化，缩略图与文字在手机放大后仍清晰。
  • 对比度： 正文墨 #3A2E26 配米白底，备注用品牌红 #B23A2E 强调，满足基本对比度。
  • 触控目标： 按钮/胶囊最小点击区 ≥ 44px；弹窗操作按钮右对齐、主操作明确。
  • 可编辑抬头： 客户姓氏与宴席类型用清晰输入框，便于销售现场更正。

8 · 交付与部署约定

  • 代码： 静态 PWA（无构建），入口 index.html + assets/{data,store,app,custom}.js + style.css + sw.js。
  • 数据两层： 菜品库存主数据与图片；菜单只存菜品库 id 引用。同菜多菜单共用图片、一处改处处同步。
  • 分支： 功能在独立分支开发，验收后再合 main；main 始终可发布。
  • 部署： CloudStudio（公网 HTTPS，PWA 可安装、断网可用）；改菜单内容在展示设备「管理」界面直接改，或导出/导入 JSON 搬运。
  • 测试： tools/custom-order.test.js（jsdom 冒烟测试，25 项断言）覆盖模式切换、分组、抬头、导出 SVG/PDF、三档字号。
令牌总原则： 任何新界面、新组件，颜色/字号/圆角/间距一律取自 :root 令牌与上文阶梯，不得引入新色值与随意间距。保证三屏一眼同源。
